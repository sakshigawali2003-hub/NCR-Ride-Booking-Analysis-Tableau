NCR Ride Booking Analysis – Tableau Dashboard

1. Project Overview

This project focuses on analyzing NCR ride booking data using Tableau to understand booking performance, revenue trends, 
ride completion, cancellation patterns and customer payment preferences.

The dashboard provides interactive visualizations to analyze ride bookings across different vehicle types, booking statuses,
payment methods and pickup locations.

2. Project Objectives

- Analyze total ride bookings.
- Calculate completed rides and booking success rate.
- Understand ride cancellation patterns.
- Analyze monthly revenue trends.
- Compare revenue generated by different vehicle types.
- Identify peak booking hours.
- Analyze payment method preferences.
- Identify the most popular pickup locations.

3. Tools and Technologies

- Tableau
- Microsoft Excel
- Data Visualization
- Data Analysis
